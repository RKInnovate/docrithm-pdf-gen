The Roboto-*.ttf files in this directory are the fonts bundled with the
`pdfmake` npm package, with their GSUB (ligature) table removed so the
generated PDF text layer maps 1:1 to Unicode. See
scripts/strip-roboto-ligatures.sh for the exact, reproducible steps.
